# Reservasi Sawah Admin

Android WebView wrapper for the existing Reservasi Sawah Worker.

- Application ID: id.reservasisawah.admin
- Minimum Android: 6.0 (API 23)
- Website: https://reserv-sawah.ayimasnoneng.workers.dev/
- Build: `gradle assembleDebug`

The APK uses the existing website login and server-side role permissions. It does not store or embed admin access codes.
